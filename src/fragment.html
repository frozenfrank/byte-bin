Step 1: Import Data

Choose Import Method Toggl API Token File Import Upload a CSV file exported from your Toggl Reports (Detailed) page. Apply appropriate filters and turn on relevant columns before generating the export.

The generated file contains only the columns enabled on the screen when the export is triggered. If information is not present on the screen, it is not in the file and therefore, unavailable for use in this tool.

The following columns are supported by this utility (order is irrelevant):

  • Description*
  • Date & Time*
  • Tags*
  • Project*
  • Billable
  • Client
  • Member
  • Email

* Indicates a required column
Your Toggl API token can be revealed at the bottom of your profile page. The token is expected to be at least 32 characters in length.
