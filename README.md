# Firebase Hosting branch

This branch of the `byte-bin` repo contains the file for publishing the CDN, including my webawesome-pro content for use with my website.

The configuration of this folder intentionally uses a symlink to an external folder on my computer with the content.
This is to avoid violating my [Web Awesome pro license](https://webawesome.com/license/pro) by posting the content publically on GitHub.

Reference the [Firebase Hosting docs](https://firebase.google.com/docs/hosting) for more information about publishing files.

## Cheat Sheet

```shell
firebase emulators:start
```

```shell
firebase deploy
```
