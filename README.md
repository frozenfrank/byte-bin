# Toggl to Delorean

Small utility that loads data from Toggl, analyzes it for review, and formats the data for entry in Delorean.

This package produces a few bundled outputs that can be executed locally or included alongside other content under a Web Awesome autoloader.

## Local Clone

Since this repository contains many independent branches, consider using the following command to clone only this branch.

```shell
git clone --single-branch --branch delorean-main git@github.com:frozenfrank/byte-bin.git
```
