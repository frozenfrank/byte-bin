# Byte Bin Blog

The personal blog of James Finlinson. This is mostly a place for me to collect and display the various projects I've worked on over time, as well as a space to tinker around with cool technologies.

This blog also hosts several small web apps. These are built and maintained as separate NPM packages and distributed here along with the blog posts.

This project is built with [11ty.dev](https://www.11ty.dev/), [Web Awesome](https://webawesome.com/), and lots of love.

## Source

The source code for this blog lives in [frozenfrank/byte-bin#blog](https://github.com/frozenfrank/byte-bin/tree/blog). The host repo contains many branches, use this command to view only this branch:

```shell
git clone --single-branch --branch blog https://github.com/frozenfrank/byte-bin.git blog
```
